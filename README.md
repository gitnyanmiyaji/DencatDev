# dencat.dev Portal System

このリポジトリは、`dencat.dev` の玄関口となるポータルサイトを管理しています。
「1枚のHTML」という軽量さを維持しつつ、情報の管理を自動化したデプロイシステムを採用しています。

## ❄️ システム構成
- **`services.json`**: **情報の核（Single Source of Truth）**。公開するサービスの情報をここに集約します。
- **`index.html`**: テンプレート兼ポータル本体。`build.py` によって動的にリストが更新されます。
- **`llms.txt`**: AIエージェント向けの索引ファイル。`build.py` によって自動生成されます。
- **`assets/`**: 季節ごとの背景画像（`month_01.jpg` ～ `month_12.jpg`）を格納します。

## ❄️ サービスの更新方法
新しいサービスを追加したり、説明を書き換えたりする場合は、以下の手順で行います。

1.  **`services.json`** を編集し、情報を追加・変更する。
2.  ターミナルでビルドスクリプトを実行する：
    ```bash
    python3 build.py
    ```
3.  `index.html` と `llms.txt` が更新されたことを確認し、Gitでコミット＆プッシュする。

## ❄️ 背景画像の変更
`assets/` フォルダ内に、対象月のファイル名（例: 5月なら `month_05.jpg`）で画像を配置してください。
ページを開いた際に、JavaScriptが自動的に現在の月に合わせた画像を読み込み、季節のエフェクト（雪、桜、泡、落ち葉）を適用します。
